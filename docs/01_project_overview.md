# CloudWatch Log Viewer - 프로젝트 개요

## 문제 정의

### 현재 상황
AWS CloudWatch에서 로그를 보려면 다음 단계를 거쳐야 한다:

```
1. AWS Console 로그인
2. CloudWatch 서비스 이동
3. 로그 그룹 메뉴 진입
4. 해당 Lambda/서비스의 로그 그룹 찾기
5. 로그 스트림 선택
6. 실시간 조회 버튼 클릭
```

**매번 6단계. 디버깅할 때마다 반복.**

### 핵심 Pain Point
- Lambda뿐 아니라 CloudWatch를 보는 것 자체가 번거로움
- 여러 계정을 사용하면 계정 전환까지 필요
- 단순히 "최근 로그 보기"를 하려는데 과정이 너무 많음

---

## 해결 방향

SDK/API를 호출해서 웹에서 바로 로그를 조회할 수 있게 한다.

```
AS-IS: Console 로그인 → CloudWatch → 로그 그룹 → 스트림 → 조회
TO-BE: 웹 접속 → 로그 그룹 선택 → 바로 조회
```

---

## 프로젝트 우선순위

1. **내가 편하려고** - 일단 동작하는 것
2. **기술 연습** - AWS SDK 경험 쌓기
3. **사내 배포** - 나중에 되면 좋고

## 단계별 목표

### 1단계 (현재)
- 내 계정 1개에서 동작
- 로그 그룹 목록 조회
- 로그 조회 (시간 범위, 키워드 필터)
- 서버 캐싱

### 2단계 (나중에)
- 크로스 계정 접근 (Role Assume)
- 여러 계정 로그 통합 조회

### 3단계 (훨씬 나중에)
- 사내 배포
- 사용자별 권한 관리
