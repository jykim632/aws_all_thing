# 2025-12-21 작업 내역

## 개요

CloudWatch Log Viewer 2단계 구현: 사용자 인증 + AWS Credentials 관리

## 배경

1단계에서는 환경변수에 AWS credentials를 설정하여 단일 계정으로 동작했음.
2단계에서는 사용자별로 로그인하고, 각자의 AWS credentials를 설정하여 자신의 CloudWatch 로그를 조회할 수 있도록 변경.

## 주요 결정 사항

### 1. 인증 방식
- **LDAP 인증** 선택 (사내 LDAP 활용)
- 개발 시에는 `DEV_SKIP_LDAP=true`로 mock 인증 사용

### 2. 세션 관리
- **iron-session** 사용 (HttpOnly 쿠키)
- 세션 만료: 8시간
- 서버에 세션 저장 안 함 (쿠키에 암호화된 상태로 저장)

### 3. 데이터베이스
- **SQLite** 선택 (better-sqlite3)
- 별도 서버 불필요, 파일 하나로 관리
- 위치: `data/cloudwatch-viewer.db`

### 4. AWS Credentials 저장
- DB에 암호화하여 저장 (AES-256-GCM)
- 암호화 키: `SESSION_SECRET` 환경변수에서 유도
- 사용자당 1개의 credentials만 저장

### 5. 타입 안정성
- **Zod** 사용하여 런타임 타입 검증

### DB 스키마

```sql
CREATE TABLE users (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  username TEXT UNIQUE NOT NULL,
  display_name TEXT,
  email TEXT,
  created_at TEXT DEFAULT (datetime('now')),
  last_login_at TEXT
);

CREATE TABLE aws_credentials (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id INTEGER NOT NULL UNIQUE,
  access_key_id_encrypted TEXT NOT NULL,
  secret_access_key_encrypted TEXT NOT NULL,
  region TEXT DEFAULT 'ap-northeast-2',
  created_at TEXT DEFAULT (datetime('now')),
  updated_at TEXT DEFAULT (datetime('now')),
  FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
);
```

### 환경변수

```bash
# 필수
SESSION_SECRET=최소32자이상의시크릿키

# 개발용 (LDAP 스킵)
DEV_SKIP_LDAP=true
DEV_MOCK_USER=testuser

# LDAP (나중에 설정)
# LDAP_URL=ldap://ldap.example.com:389
# LDAP_BIND_DN=cn=admin,dc=example,dc=com
# LDAP_BIND_PASSWORD=password
# LDAP_BASE_DN=ou=users,dc=example,dc=com
# LDAP_USER_FILTER=(uid={{username}})
```

## 사용 흐름

```
1. 로그인 페이지 (/login)
   └── LDAP username/password 입력
   └── 인증 성공 → 세션 쿠키 발급 → 메인 페이지로 이동

2. 메인 페이지 (/)
   └── AWS credentials 미설정 → "설정으로 이동" 안내
   └── 설정 완료 → 로그 그룹 목록 + 로그 뷰어 표시

3. 설정 페이지 (/settings)
   └── AWS Access Key ID, Secret Access Key, Region 입력
   └── 저장 → DB에 암호화 저장
   └── 기존 credentials 있으면 마스킹 표시 + 삭제 가능

4. 로그 조회
   └── API 호출 시 세션 확인
   └── DB에서 사용자 credentials 조회 (복호화)
   └── AWS SDK로 CloudWatch API 호출
```
